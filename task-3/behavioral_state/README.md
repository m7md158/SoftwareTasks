## The State design pattern is:
 - a behavioral software design pattern that allows an object to alter its behavior when its internal state changes. 
 - It achieves this by encapsulating the object’s behavior within different state objects, and the object itself dynamically switches between these state objects depending on its current state.


## 🧠 Main Idea: Operating System

 - The computer's operating system goes through several states such as 
    - "Sleep"
    - "Active"
    - "Shutdown".
 - Each state changes the system's behavior based on its current state.
